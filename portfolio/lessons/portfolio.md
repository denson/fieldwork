# Fieldwork: the shared portfolio

[Open the portfolio](../?demo=home) · [Fieldwork Portfolio Guide](https://box.boodle.ai/a/@FieldworkPortfolioGuide)

Four hands-on activities for curious adults and older teens, with a BoodleBox guide for each. New visitors start at the website homepage with First Steps, then come here to choose an investigation. Return to this portfolio whenever you want another activity. Returning visitors can skip First Steps. This is an independent portfolio by Denson Smith.

## Move between activities

In Chrome split view, keep BoodleBox on the left and this website on the right. With Fieldwork Companion Pane 0.4.1 enabled, activity choices and Back to portfolio links switch both sides to the matching pair. The plain homepage opens First Steps; ?demo=home opens this portfolio. Every companion knows the explicit portfolio link. Ask for “the portfolio” to get it without completing a lesson first. After First Steps, the portfolio may remember your topic interest; this does not transfer answers or prove completion.

A different guide starts a separate chat. Earlier sent conversations remain in BoodleBox history; they are not copied into the next conversation. An unfinished chat draft blocks changing guides until you send or clear it yourself. History notes and civic work are kept in the website tab's browser storage through portfolio visits; closing the tab or clearing browser data can remove them. Download important work. The tsunami investigation and First Steps use their own browser saves.

Without the extension or a paired chat, open an activity and its guide directly, choose Start New Chat on the guide profile, and keep them beside each other. BoodleBox sign-in is required.

## You approve the handoff

Website choices become a prepared note. Put note in BoodleBox places the note in the matching chat's empty draft. Review it and press Send to approve sharing. The guide then receives that note; it does not receive every click automatically. This approval step is human in the loop (HITL). Copy/paste remains available.

The website is publicly available at https://denson.github.io/fieldwork/ . Guides use the public lesson references, their supplied copies, and the learner's deliberately shared notes.
