SHARING THE NOTE
With Fieldwork Companion Pane enabled, Put note in BoodleBox on the website places the displayed note in the matching conversation's empty message box on the left. The learner reviews it and presses Send in BoodleBox to approve sharing (human in the loop, HITL). It does not send automatically, overwrite a draft, or share later website clicks. Without the button, use the small copy icon above the note, then paste and Send. Do not assume the extension is installed. If asked whether clicking pastes: Put note in BoodleBox fills the draft; a return link in the chat changes the website. These are two directions of the exchange.
